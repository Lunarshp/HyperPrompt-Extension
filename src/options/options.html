关于本扩展

HyperPrompt

强大的提示词生成和管理工具，支持多个AI模型进行图像分析、提示词生成和文本翻译。

功能特性：

  • 支持多个 AI 模型 (OpenAI, Gemini, GLM, Qwen, DeepSeek, Grok)
  • 图像智能分析，自动生成提示词
  • 多语言翻译支持
  • 提示词历史记录和收藏
  • 自定义规则：让反推、扩写和翻译按你的习惯输出
  • 一键复制和导出功能

怎么用

  1. 在 API 管理器配置服务商密钥（图像反推需视觉模型）
  2. 打开任意网页，鼠标悬停到图片/视频上，用悬浮按钮反推提示词
  3. 悬停时右下角出现 HP 胶囊：批量反推、视频反推、提示词优化、历史都在这里
  4. 结果自动存入历史，加标签沉淀成你的提示词素材库
