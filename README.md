# HyperPrompt

AI 创作者的提示词工作站，Chrome 扩展。把网页上的图片、视频和一句简短描述，变成可以继续编辑、翻译和复用的提示词。

永久免费，源码公开，数据只保存在本机。

## 功能

- 图像反推：悬停网页图片，或上传本地图片，生成提示词。
- 视频反推：从视频里选关键帧，生成包含镜头、运动和节奏的提示词。
- 提示词优化：把简短描述扩写成结构完整的生成指令，可附参考图。
- 翻译：翻译提示词，保留结构和模型参数。
- 自定义规则：用内置规则，或自己写，决定反推、优化、翻译怎么输出。
- 历史标签：结果自动存入历史，可打标签、筛选，整理成可复用的素材库。
- 本地备份：把历史、规则和设置导出成 JSON 文件，随时恢复。

## 安装

要求 Chrome 111 或更高版本。

1. 下载或克隆本仓库。
2. 打开 `chrome://extensions/`，开启右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。

## 配置服务商

HyperPrompt 不自带模型，使用你自己的服务商。右键扩展图标，选「选项」打开设置页，进入「API 管理器」，选一家服务商，填入 API 密钥和模型名。

内置预设有 OpenAI、Gemini、智谱 GLM、通义千问、DeepSeek、Grok。也可以添加任何兼容 OpenAI 接口的服务，或使用本机的 Ollama。

请求直接从你的浏览器发到服务商，费用由服务商收取。
